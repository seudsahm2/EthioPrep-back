# Question Access Control

Free users have limited access.

Limits:

Simple explanation → 20 questions
Detailed explanation → 10 questions
Deep explanation → 5 questions

After reaching the limit, users must upgrade.

Backend must enforce these limits.

# Subscription / Payment System

Users can purchase access.

Packages:

Simple package → 50 birr
Detailed package → 100 birr
Deep package → 200 birr

Payment flow:

User clicks upgrade.

Backend generates payment request.

User uploads payment screenshot.

Admin verifies payment.

User account is upgraded.

Payment model fields:

```
user
package_type
amount
payment_screenshot
status
created_at
verified_at
```

Future integration support:

Payment gateway integration for **Chapa.

Design code so it is easy to add automated payments later.
